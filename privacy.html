隐私政策

Syncscribe · 最后更新：2026年9月26日

本政策说明 Syncscribe 如何处理您的信息，包括本地媒体处理、可选网络功能、订阅购买及支持反馈。

1. 音视频、转写与翻译

  • Whisper 转写：优先在您的 Mac 上使用 Whisper 模型处理音频，不需要把音频上传至开发者服务器。
  • Apple 语音识别备用路径：当 Whisper 转写失败或没有结果时，应用可能自动切换到 Apple 语音识别。支持设备端识别时使用本地处理；不支持时，音频可能发送至 Apple 进行识别，并适用 Apple 的隐私政策。因此，并非所有识别路径都完全离线。
  • 翻译：使用 Apple 设备端翻译功能，可能需要先联网下载语言包；翻译文本在设备上处理。
  • 编辑与导出：剪辑、画中画、视频拼接、封面制作及画面修复在本地处理媒体。应用需要读取您授权访问的文件，并在本机保存工作数据和导出结果。

2. 网络连接与第三方服务

应用不集成用于广告追踪或行为分析的第三方 SDK。以下功能可能需要网络连接：

  • Apple 语音识别的云端备用路径、翻译语言包下载，以及 App Store 商品加载、购买和恢复购买。
  • 您主动使用的 URL 文件下载、模型或运行时组件下载（如适用）。文件或下载服务的提供方可能接收 IP 地址及完成网络请求所需的信息。
  • 您主动打开的支持网站、隐私政策网站或外部链接。这些网站由各自提供方处理访问请求。

本政策网页托管于 GitHub Pages。网页访问可能由 GitHub 按其隐私声明处理。Apple 与 GitHub 的处理规则请参阅 Apple 隐私政策及 GitHub 隐私声明。

3. 订阅与购买验证

Pro 订阅由 Apple App Store 处理。应用通过 StoreKit 获取和验证商品、交易及购买权益信息，以解锁相应功能并支持恢复购买。开发者不接收您的银行卡号或其他付款凭据。Apple 对账户和付款信息的处理适用其隐私政策。

4. 本地存储、保留与删除

应用可能在本机应用数据目录中保存剪辑草稿、项目设置、转写或编辑数据、模型及缓存。自动保存的剪辑草稿并不一定位于您手动选择的导出目录。导出文件和您另存的项目保存到您指定的位置。

本地数据可能保留至您删除相关文件或应用数据。您可以在 Finder 中删除不再需要的导出文件或另存项目；如需清理应用目录内的草稿和缓存，请通过支持渠道获取帮助，并先备份需要保留的项目。删除应用本身不应视为已删除所有导出文件或应用数据。

若您选择的文件夹由 iCloud Drive 或其他同步服务管理，文件可能依据您对该服务的设置同步；这不属于 Syncscribe 自行向开发者服务器上传媒体。

5. 权限与您的选择

应用可能请求文件访问和语音识别权限。文件权限用于读取您选择的素材和保存结果；语音识别权限用于 Apple 识别路径。您可以在 macOS 系统设置中管理适用权限。拒绝或撤销权限可能导致相应功能不可用。若不希望音频进入 Apple 云端识别，请不要使用可能触发该备用路径的功能；当前不能保证所有识别请求仅在本地完成。

6. 支持与反馈

当您主动联系支持或提交反馈时，我们可能接收您提供的联系方式、问题说明、日志或附件，并用于处理该请求。请仅提供排查所需的信息，避免包含敏感媒体、密码或付款资料。我们按处理支持请求所需的时间保留相关信息，法律另有要求的除外；您可通过原支持渠道提出删除请求。

7. 儿童隐私

本应用不面向 13 岁以下儿童。我们不会故意收集儿童的个人信息。如您认为儿童通过反馈渠道提供了个人信息，请联系我们处理。

8. 政策更新与联系

政策更新会在本页标明日期。如处理方式发生重大变化，我们会按适用要求提供通知，并在需要时征求同意。

隐私问题或数据请求，请使用应用内“用户支持与反馈”或 项目 Issues 联系我们。GitHub Issues 是公开的，请勿在其中发布个人信息或私密文件。
